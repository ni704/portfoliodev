## 🚀 Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `portfolionickdev`).
2. Envie **todos os arquivos desta pasta**, mantendo a estrutura de pastas.
3. Confirme que `index.html` está na raiz do repositório.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.

### ⚠️ Importante

Não mova a pasta `assets`. O `index.html` usa caminhos relativos como `assets/css/main.css` e `assets/js/main.js`, que funcionam no GitHub Pages mesmo quando o projeto está em `seuusuario.github.io/nomedorepositorio/`.
